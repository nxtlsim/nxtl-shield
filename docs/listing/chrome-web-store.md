## Detailed description
What is NXTL Shield?

NXTL Shield is a free, open-source Firefox extension from NXTL eSIM. It helps you stay safer when you browse: it warns on known phishing and malware sites from bundled threat lists, can block tracker domains, cleans common tracking parameters from links, can hide cookie banners, and on compatible Chromium builds paired with the web app workflow it supports location controls. The companion web app at nxtlsim.github.io/nxtl-shield adds more tools you can run in the browser without installing anything.

Features in this extension
• Threat warnings for known bad hosts from bundled lists you can turn on
• Optional tracker-domain blocking
• Conservative link cleaning that leaves signed, login, and payment links alone
• Cookie-banner hiding (hides some banners; it does not reject consent for you)
• Works with the free NXTL Shield web app for link checks, Secure Share, DNS setup guides, and more
• No account required

Who it is for
• Travellers and people on public Wi-Fi who want an extra check before opening a link
• Anyone who wants tracker and tracking-parameter cleanup in the browser
• Privacy-minded users who prefer free, open-source tools they can inspect

Privacy
Shield’s extension logic runs in your browser. There is no NXTL account for the extension, and NXTL does not collect your browsing history through this add-on. Threat and tracker rules ship with the extension as bundled lists. The optional web tools that look up a breached-password range hash, public IP, or NXTL pricing are separate browser features and are described on the Shield site; they are not required to use this extension.

FAQ
Is NXTL Shield free?
Yes. The extension and the web tools are free. NXTL eSIM mobile data is an optional paid product and does not unlock Shield.

Does it collect my browsing data?
No. The extension does not send your browsing history to NXTL. Settings stay in the browser. Bundled lists are included in the add-on package.

Does it work with Google Maps location?
On Chromium, the companion location controls can block site geolocation and allow chosen map sites. Firefox does not expose the same location content setting, so that control is not available there.

Do I need an NXTL eSIM to use it?
No. Shield works without an NXTL eSIM. eSIM connectivity is optional.

Where do the block lists come from?
They are free public host lists bundled into the extension. Details and licences are in the project source documentation.

How do I get updates and report a problem?
