# Support

| Where | Checks | Extension | DNS | Notes |
|---|---|---|---|---|
| Chrome and Edge on a computer | Yes | Load the unpacked or release zip | Chrome secure-DNS steps, or the system steps | Location blocking is available in the extension |
| Firefox on a computer | Yes | Release installs need Mozilla’s signature. The published XPI is unsigned | Firefox DNS-over-HTTPS steps | Location control is unsupported |
| Safari on a Mac | Yes | Not packaged | Apple DNS profile | Add to Dock from the File or Share menu |
| Chrome on Android | Yes | Chrome on Android does not run extensions | Private DNS hostname | Install from the browser menu |
| Safari on iPhone and iPad | Yes | Not packaged | Apple DNS profile, installed by you | Share, Add to Home Screen. iOS 27 wording for that menu was not re-checked |
| Samsung Internet | Expected | Not a target | Android Private DNS. The Samsung menu path was not re-checked | |
| TV and routers | No | No | Only if the device has its own DNS settings | |
